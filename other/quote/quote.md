# tell someone is wrong
1. The Effort Buffer
Goal: Acknowledge the initiative to prevent an immediate defensive posture.
Mechanism: Start with positive or neutral recognition of the action taken ("Thanks for taking a pass at this...").
2. Externalize the Blame
Goal: Attribute the error to inputs, tools, or missing context rather than the individual's capability.
Mechanism: Frame the flaw as a system issue ("It looks like some context was missing in the prompt...") instead of a personal failure ("You missed key details").
3. Softened Precision
Goal: Be explicit about the problem while stripping out punitive language.
Mechanism: Swap absolute or loaded terms like "wrong," "incorrect," or "skill gap" for constructive equivalents like "slightly off," "needs alignment," or "requires fine-tuning."
4. Shared-Win Horizon
Goal: State the desired change as a collective benefit rather than a reprimand.
Mechanism: Reframe negative outcomes ("so we stop wasting tokens") into positive goals ("so we can optimize token efficiency across the team").

# defend and align
1. Lead with Positive Validation
The Skill: Relationship management and feedback encouragement.
The Shift: Instead of jumping straight to internal logic ("For runtime..."), open by validating the sender's effort.
Application: Start immediately with positive reinforcement so the stakeholder feels heard before you explain system constraints.
2. Explain the Strategy and the "Why"
The Skill: Strategic storytelling.
The Shift: Replace vague goals ("attack broad patterns") with the underlying rationale for your prioritization.
Application: Name the business mechanism driving your choices (e.g., "compounding spend across the fleet") so your default focus makes logical sense to outsiders.
3. Reframe Defensive Limitations into Value
The Skill: Constructive reframing.
The Shift: The original phrasing presents tenant-specific work as "reactive" and lower priority. The revised version treats tenant reports as high-value diagnostic inputs ("leads, not one-offs").
Application: Never label your response to a user as "reactive." Frame single-tenant issues as the primary evidence used to uncover system-wide solutions.
4. Ground the Response in Concrete Data and Actions
The Skill: Precise operational execution.
The Shift: Move from abstract promises ("we will go deep") to specific references, explicit data requests, and a clear feedback loop.
Application: Call out the specific assets/IDs, request the exact artifact needed (dashboard link), and explicitly promise a return update.
